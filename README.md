# psplatformer

The world needs a great platformer. A shining beacon of tight controls, gorgeous art, and level design so clever it makes grown adults weep.

Instead, the world gets PS Platformer.

Built entirely in PowerShell, a language Microsoft designed for managing servers and absolutely nothing fun, PS Platformer asks the bold question: "What if Mario, but powered by the same thing your IT department uses to reset passwords?"

And yes, it has a real GUI. Actual windows. Actual graphics, lovingly drawn in MS Paint with the spray can tool and zero shame. Somewhere, a Windows XP desktop is feeling a disturbance and doesn't know why.

Features:

Graphics hand-crafted in MS Paint, circa 2004. Every pixel placed with the steady hand of someone using a mouse on a desk with crumbs on it. The color palette? Whatever was in the default swatches.
Physics that technically exist. Gravity is more of a suggestion.
A frame rate best described as "contemplative."
Jumping. That's the whole mechanic. We worked very hard on it.
Zero game engine. Why use Unity or Godot when you could suffer instead?
Enterprise-grade execution policy errors before you even get to play. Some say this is the real first level.

Is it fun? Define "fun." Is it a game? Legally, yes. Will it change your life? It will take a few minutes of it, which is more than most things can say.

Run it, jump around, and then go play a real platformer. You've earned it.

Requires: Windows, PowerShell, and extremely low expectations.
